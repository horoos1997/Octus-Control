# Octus Control

Octus Control is a Windows utility for system diagnostics, hardware monitoring, and maintenance.

## Features

- Hardware information and monitoring
- System diagnostics
- Windows system information
- Driver information

## System requirements

- Windows 10/11 (64-bit)
